# Sphere Gradient Icon Pack

**Icon pack de esferas 3D con degradados** para Samsung One UI + Theme Park.

## Características
- Esferas 3D realistas con degradados y highlights
- Colores personalizados: azul, púrpura, cian, rosa, naranja
- Compatible con Theme Park (One UI)
- APK listo para instalar

## Cómo usar
1. Descarga el APK desde **Releases**
2. Instálalo en tu Galaxy
3. Abre **Theme Park** → pestaña **Icon** → **Create New**
4. Toca el botón **Iconpack** (regalo)
5. Selecciona **Sphere Gradient**
6. Ajusta forma/efecto si quieres y aplica

## Compilación automática
Cada push a esta rama (`icon-pack-oneui-spheres`) dispara GitHub Actions que:
- Compila el APK release
- Publica automáticamente una nueva Release con el APK
